  - **Finding: physics is identical *without weather*.** Zero position/altitude/speed/heading divergence over 600 s — the whole gap between the paths is ATC/track state, which is what ADR 0003 relocates. 1b's weather fixture is the exception and the only thing in the oracle that moves an aircraft
  - [x] **1b — the missing legs and the two blind-spot fixtures**, shipped 2026-09-02 (yaat `4b11ac6`/`c581a72f`/`e7be3fdc`/`fb9289bd`, yaat-server `72810531`/`dc48160a`/`06dbeee6`/`8bebf36a`). Four run kinds now, three fixtures, nine baselines at `<fixture>.<pair>.baseline.json`; 25 s in the default suite. This is what unblocks 3b
    - **`live-vs-replay`** — `ReplayOneSecond` runs the *same* `TickPrePhysics/TickPhysics x4/TickPostPhysics` sequence as `TickOneSecond`, so it differs only in the replay guards. Predicted the same 14 paths as live-vs-test before generating; got exactly that. The leg is therefore the instrument for 3b rather than new information today. Rooms are loaded through the server's own `LoadScenarioSeededAsync` and armed afterwards via the new `SimulationEngine.ArmReplay`, so the scenario load is not a variable
    - **`live-vs-reconstruct`** — `RecordingManager.ReconstructViaServerTick`, the only genuinely different code path (it runs the live `TickProcessor` post-physics list). Predicted one path, position history; got exactly that. Near-disjoint from the other two, the shape ADR 0003 predicts
    - **`weather` fixture** — a sub-threshold wind ramp separates all three advance semantics at once (live gated by `HasMeaningfulChange`, replay/reconstruct ungated, engine absent). **This is the oracle's first physics divergence**: wind, track, heading, position, then altitude and speed. Every weather-less sweep still shows physics identical on all four run kinds
    - **`autodelete` fixture** — has to use the queued-`DEL` branch: `ScenarioLoader.cs:423` exempts every scenario-declared aircraft, so the `Parked`/`OnLanding`/departed-overflight gates are unreachable without generated traffic. The sweep asserts an aircraft actually disappeared, since a fixture that stops reaching its gate produces a spotless baseline that reads as agreement
    - All 70 new entries attributed. Three paths were not predicted (`Declination`, `Phases.ConfigSet`, the beacon-code pool) and are second-order consequences of ones that were
    - Also landed: `Describe`'s shrink branch now reads as a regression and withholds the re-baseline command (the trap recorded below), pinned by `TickOracleBaselineTests`; and regeneration is byte-stable, so anything `git status` reports on a baseline is a real change
  - **Blind spots that remain** (recorded in the test's doc comment): coordination timers and solo-training evaluation reach no fixture; **the replay leg is weaker than it looks** — no fixture declares a runtime generator, so the generator stand-down guard is never reached (asserted, not assumed), and recording suppression is invisible in principle because the action log is not simulation state and is not in `ScenarioSnapshotDto`
  - **Blind spot found 2026-09-04 — action-application fidelity is outside the oracle's reach by construction.** Both oracle legs replay the same action log through the same applier, so an action the live server applied through a *different arm* than replay does never shows up as a divergence path. Found from the S2-OAK-5 bundle: the CRC `AS 3O DA R22` echo was recorded beside its `RecordedAmendFlightPlan`; live routed it through the flight-plan arm, reconstruction pushed it through `CommandDispatcher`, and a `VfrHoldPhase` cancelled on it — the bundle's snapshots showed the R22 flying off while the live log kept it hovering. Fixed by `RecordedCommandKind.FlightPlan` (both replay paths skip; dispatcher refuses at its public entries). Pinned by replay-vs-live-log tests on the real recording (`FlightPlanCommandReconstructionKeepsPhaseTests`, `FlightPlanCommandReplayKeepsPhaseTests`). **The class is step 3d below** — the 2026-09-05 audit found it was one of eight, and `bug_bundle.py history` tags CRC echoes (`CRC`) so a bundle triage sees them
