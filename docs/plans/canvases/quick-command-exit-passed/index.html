Row templates, glyphs and fonts follow the X1 choices mock (docs/plans/canvases/quick-command-exit-choices/) and the built ExitFlyout.cs: Inter text, commands in JetBrains Mono at 70%, 22 px glyphs at stroke 1.9 in the tower colour drawn at each exit's turn-off angle, the Fluent dark menu surface, a dropped row at 38% with its state in amber, the box's match rows as the build draws them (taxiway in bold, distance, command).
