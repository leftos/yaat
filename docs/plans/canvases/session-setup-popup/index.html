Session-setup popup (YAAT-1180)

The Active Runways overlay becomes one session-setup popup with sections; each shows only when it applies and is not already settled, and with nothing to ask there is no popup. Lanes A to C are the three states. Lanes C and D differ only in how the positions section is chosen (radio list or drop-down). Lane E is the new row in the session settings flyout (dashed). The student here works OAK_GND, so the choices are Ground and Delivery; an approach student would see Approach, Tower, Ground and Delivery.
