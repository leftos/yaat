Cleared visual: only visuals

The owner ruled that Cleared visual “should offer only visuals for all available runways, not other approaches”. Today the entry opens the whole Cleared approach flyout (runway tabs, each a Visual RWY n row then that runway's instrument approaches, a Circling tab, a pinned instrument default, the Approach box sending CAPP {typed}) and only opens on the visual row. This page asks three things: the layout and title, the typed box, and which runways get a row. Each artboard has lanes A, B and C; no lane is marked recommended.

Already decided and drawn in every lane: no instrument rows, no Circling tab, no pinned instrument default; the Force toggle in the title line stays (rows then send CVAF {rwy} and wear the force mark); Cancel IFR… (CIFR) stays at the bottom, as built for a destination with instrument approaches; a visual row is greyed “field not in sight” until the pilot reports the field. The untowered-field “Visual approach to {airport}” row stays where it applies; KOAK is towered, so it is not drawn. Click a row, a tab, the Force toggle or type in a box to see what it does.

Rows follow the built MenuGlyphRow as the x3 mocks draw them (docs/plans/canvases/yaat-569-x3-approach/ on feat/context-menu-flyouts): Inter text, notes after “ · ”, commands in JetBrains Mono at 70%, the whole row at 50% when dimmed, 22 px glyphs at stroke 1.9 in the flight colour, the Cleared visual eye on every visual row. The force mark (filled amber badge, amber command), the title line with the Force toggle at its right, the greyed note “field not in sight” and Cancel IFR… with no glyph are drawn as the built ApproachFlyout draws them. The flat lists, the “Cleared visual approach” title, the Runway box and its refusal line, the “Other runways…” row and the empty-room line are drawings of the options, not built UI. The blue ring marks the row keyboard focus lands on as the flyout opens; the dashed notes are mock annotations. The page loads no web fonts and shows no image files.
