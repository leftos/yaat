YAAT-2515 · Q10: map imagery under the Airport Editor

YAATEdit draws satellite or OSM tiles under its maps. What should YAAT's Airport Editor draw under the taxiway and runway lines? Each lane is the same view of Oakland (KOAK) north field at the same scale (web-mercator zoom 15, 1:1 tile pixels), with the airport's real vNAS layout drawn over it the way the editor draws it.
