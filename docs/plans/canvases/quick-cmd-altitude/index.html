A · YAAT-2237: Accept, Cancel and Acknowledge in the quick list

An IFR arrival (SKW3422 · E75L, 11,000 ft, 250 kt) whose quick list is today's default for the IFR arrival situation: Descend via STAR, Expect approach and Hold under APPROACH, Maintain altitude, Assign speed, Fly heading and Direct to under VECTORS. Each new entry is a Track and coordination entry and shows only in its own state, so the three never appear together: Accept handoff for a handoff to the acting position, Cancel handoff for one from it, Acknowledge pointout for a pointout pending to it.

The rows are placed in the list right after Squawk assigned code (the Squawk precedent: first in every list). The first menu of each lane is whole; the other two are cut below the quick commands, since the rest of the menu is the same.

A1

Text rows, no glyph

Shows
A glyphless entry is a text row below the strip, with its alias at the right, as Track's rows read under All Commands today. The strip is unchanged.
Code
EveryDefaultQuickCommand_HasAGlyph fails for a glyphless default entry, so the test is relaxed for these three.
A2

New glyphs, so the entries join the strip

Shows
Every glyph-bearing entry is a strip button, so a glyph moves the entry onto the strip under TRACK AND COORDINATION; the name shows on hover in the header's line. With icons off it is a text row as in A1.
Glyphs
Accept: the receiving bracket closed by a check. Cancel: the Initiate handoff bracket with the arrow turned back. Acknowledge: the Point out hand with a check. Grey scope family, stroke 1.9.
Note
Placed first, the one-icon Track segment shares the row with APPROACH and its label truncates to "TR…", as the strip trims any long label; placed last it would share VECTORS' row instead.

B · YAAT-2240: one "Altitude…" quick command for VFR aircraft

N302AB · C172, VFR at 4,200 ft, magnetic track 095°, nearest field elevation 600 ft. Eastbound, so the VFR cruising altitudes are odd thousands + 500; only those more than 3,000 ft above the field are highlighted, so 3,700 ft and above qualifies: 5,500, 7,500, 9,500 … are highlighted and 3,500 (2,900 AGL) is not. Every altitude stays selectable to the 100 ft. Modes: Maintain (CM, and DM below the aircraft as today), At or above (CM A), At or below (CM B), sent in full feet as CM A5500.

VFR cruising altitude (the Speed flyout's outlined chip: 2 px #8FC1FF) now (the Maintain list's now row) row under the pointer or keyboard chosen column cell (toggle-on fill)
B1

Scroll list in 100 ft steps

Shows
Today's Maintain list at 100 ft all the way up, with the mode toggle of Cross fix's Cross at. It opens centred on the now row.
Cost
Cruising altitudes are 20 rows apart and the list shows about 10, so as it opens no highlight is in view; 5,500 is 13 rows up (second panel).
Clash
The list already outlines the row nearest the typed box in the same #8FC1FF; one of the two needs another mark.
B2

Thousands + hundreds columns

Shows
Pick a thousand, then a hundred; the hundred sends. A thousand is highlighted when its +500 is a cruising altitude, and with it chosen its 500 is too. The header shows the value and command before sending.
Cost
Two clicks for every altitude; the whole range fits in one short scroll. A new control, not today's list.
B3

500 ft list + fine nudge

Shows
Today's 500 ft rows with the now row inserted, the cruising rows highlighted. The row under the pointer or keyboard carries −100 / +100 chips that step its value, its command following; a click on the row sends.
Cost
One click for a cruising altitude; an odd hundred needs nudges (or the box).

Two states, drawn in B1's style

The same rule whatever the option: no highlight where no listed altitude is more than 3,000 ft above the field, and none while the aircraft turns, since its course is not settled.
