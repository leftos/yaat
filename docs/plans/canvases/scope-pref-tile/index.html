YAAT Scope: where the PREF tile goes (YAAT-2396)

The Scope bar packs its buttons as STARS does: a button showing a value is a full-height tile, consecutive buttons without one stack in half-height pairs, and one left without a partner is a full tile. PREF shows the active pref set's name as its value, so today loading or clearing a set turns PREF from a half tile under BRITE into a full tile, BRITE becomes a lone full tile, and DEL TEAROFF jumps along the bar. Which shape should PREF take so the bar stops moving? Each lane draws the bar twice at 1 CSS px = 1 DIP, left-aligned in a 1360 DIP window: with no pref set, then with pref set SR-DAY active. The dashed gold line marks DEL TEAROFF's left edge in the first frame and runs down through the second, so any shift shows at a glance. Every width below is measured off this page as it renders.
