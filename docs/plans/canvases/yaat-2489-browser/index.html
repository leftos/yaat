YAAT-2489 · Scenario Editor browser sidebar

Tools > Scenario Editor: a non-modal window (about 1100 × 700) with a sidebar listing ZOA's server scenarios (downloaded mirrors) and local working copies. The content area stays empty until the tabs arrive in a later milestone. Every mock is drawn at real pixel size in YAAT's dark theme; lanes show only the sidebar end of the window (the dashed edge is where the crop cuts). One ARTCC is shown as a label, with no selector; Refresh is manual and runs once when the window opens.

V4 · Import id conflict

When an imported file's id is already used, which dialog should ask what to do?

Lane A Three buttons: New id / Keep id / Skip
Import scenarios✕

This id is already in use

File 2 of 5 · oak_gnd_1.json

The scenario “OAK_GND - Oakland Ground 1” has the id 01H06NVK7VN8BS7MCDXHKJZ7MQ, which your working copy “OAK_GND - Oakland Ground 1” already uses.

  • New id imports it as a separate local copy with a fresh id.
  • Keep id replaces your working copy with this file.
  • Skip leaves this file out.
