YAAT-2442: the scope-data column in the Scope's field menus. Which widget holds it?

Clicking a field of an ERAM data block on the YAAT Scope opens a field menu. Today that is a one-entry ContextMenu holding a pilot-command catalog entry (the altitude field opens Maintain altitude with its flyout already open). YAAT-2442 adds scope data rows beside it: ERAM entries (QZ, QQ, QR) that run through the Scope's ERAM entry path instead of sending a pilot command. The question is which menu widget holds those rows. Both lanes show the same scene: UAL238's ERAM full data block (selected), its altitude field 250C just clicked, FP altitude 250 and no interim set. The top frame of each lane is the menu as it opens; the bottom frame is the pointer reaching the scope-data row Interim, with 180 typed in the altitude box.

The same rule applies in both lanes. A click on a row sends it: a pilot row sends its command for UAL238, and a scope-data row runs its ERAM entry at once, with ACCEPT or the ERAM refusal shown in the feedback area. A Shift+click stages the row in the preview area instead: PILOT UAL238 DM 23000 for a pilot row, or the bare entry QQ 180 UAL238 for a scope-data row, ready to edit and send with Enter.

Lane A: Submenu

Today's catalog menu gains a second entry, Scope data ▸, whose submenu holds the scope-data rows. Click a row: it sends (pilot) or runs (ERAM entry). Shift+click: it is staged in the preview area.

Stays a ContextMenu, so today's Shift recording (ScopeFieldMenus.RecordShift) carries over. Only one column shows at a time, and scope data is one hover away.

What is real and what is approximated
  • Real, from the code: the pilot rows, marks and colours are today's Maintain altitude flyout (AltitudeFlyout, MaintainAltitudePanel, FlyoutPanelParts). The ERAM preview and feedback box and the PILOT gold / ERAM cyan kind colours come from ScopeEntryLayer. The white block, blue symbol and black background come from ScopeRenderer. The scope-data entry text uses the grammar in the step-5 map, 5i (QZ alt, QQ, QQ L, QQ alt, QQ Lalt, QQ Palt, QQ Ralt, QR alt).
  • Approximated: the app's UI font is Inter, drawn here in Segoe UI. The Fluent menu chrome (#2b2b2b, its border and corner radius) is matched by eye to whats-new-altitude-flyout.png. The ERAM block's line 3 and line 4 text and its 13 px Consolas size are illustrative.
  • Not decided by this mock: how a scope-data row gets its altitude. Here one altitude box feeds every row that takes one, and those rows read ··· while the box is empty. The column order SCOPE DATA | PILOT follows board 04 in the step-5 map.
