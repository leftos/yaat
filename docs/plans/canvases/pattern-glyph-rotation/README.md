# Pattern glyph rotation mock

`pattern-glyph-rotation-mock.html` is the design mock for YAAT-521's pattern-entry runway flyout.

The mock rotates each glyph by the runway's magnetic heading; the build rotates by the runway's true course (true course − 270°) and mirrors the glyph for right traffic. Where the mock's intro, `headingOf` and open questions 1 and 3 say magnetic, the build supersedes them. `docs/client-context-menus.md` ("Pattern-entry runway flyout") describes the flyout as built.
