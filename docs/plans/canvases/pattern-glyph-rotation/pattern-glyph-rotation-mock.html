Open questions

  • Magnetic vs true: the glyph turns by the runway's magnetic heading (its number), as asked. The ground view and radar are drawn true-north-up, where OAK's runways sit about 13° clockwise of their numbers, so a glyph is about 13° off the drawn runway at OAK. Rotating by the true course instead would line up with the map exactly.
  • Make straight-in picks its frame from the runway's default pattern side (YAAT's rule today: an L/R parallel sends its pattern outboard, so 28L/10L left and 28R/10R right; a single runway is left traffic). The strip default, with no runway, is left.
  • The strip button keeps the default lands-west glyph. An aircraft already assigned a runway (on final, in the pattern) could show its runway's rotated glyph on the button too.
