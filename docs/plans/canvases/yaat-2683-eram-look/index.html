YAAT-2683: how should the YAAT Scope draw ERAM tracks?

In the Mixed template a STARS-owned track and an ERAM track sit side by side, and today they look the same apart from the datablock's text layout. Each lane below draws the same small Mixed scene: two STARS tracks (always drawn as today) and six ERAM tracks, one of each state an en-route controller meets. Pick one lane in Section A; Sections B and C only matter if that lane brings a new font or ERAM glyphs.

Every element is labelled in grey beside its lane, never on the scope. Text content is the same in every lane (what YAAT's eram template prints today); only the drawing changes. ERAM glyphs here are YAAT's own drawings from descriptions of CRC's shapes (12 x 15 px cell, 2 px strokes, no antialiasing); no CRC font or bitmap is copied.

View at 100 % browser zoom on a 100 % display scale: every scope is drawn 1 screen pixel = 1 CRC pixel. A scaled page blurs the pixel glyphs and makes them look bigger than they would on the Scope.

Section A: overall look (the main question)

CRC's leader "length 1" is min(display width / 32, 60) px, drawn here as 60 px (a 1920 px-wide Scope). Colours: CRC's ERAM yellow at its default brightness groups (targets 200,200,0; FDB 196,196,0; LDB 129,129,0; history 34,34,0); YAAT's symbol blue 0,176,255; STARS ownership white (own) and 50,205,50 green (others).

Section B: datablock font (only if the lane picked brings a new font)

The A2 scene's FDB (UAL123, with its target glyph, track-position diamond and leader) and a limited block (N512RK) in ERAM yellow, in each candidate font. Row pitch follows CRC's rule (cap height + 7 px). The outline fonts draw antialiased as YAAT draws text today; VT323 is a pixel face and draws aliased at sizes where its pixel grid lands on whole screen pixels: 25 px is pixel-exact (10 px advance, CRC's default size-1 advance), 12.5 px is a half grid and is the nearest crisp size to 12 px.

Section C: symbol set (only if the lane picked uses ERAM glyphs)

CRC draws two layers: the target glyph (the radar return, by state) and, under an FDB, a separate track-position symbol at the same point. The key shows each glyph at 1:1 and at 4 x (pixels enlarged, not redrawn). The lanes are all A2 otherwise.
