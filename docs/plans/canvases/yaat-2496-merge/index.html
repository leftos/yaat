YAAT-2496 · Scenario merge view

A three-way merge window for the Scenario Editor. Mine is my working copy; Theirs is the newer server version, an imported file, or another scenario picked in the browser. Each pane looks like the editor's own tabs (the General form, the aircraft grid, one aircraft's detail editor), read-only; a one-sided change merges by itself and only a clash asks. The base shows on demand. Nothing is saved until Apply. Every window is drawn at real pixel size in YAAT's dark theme (Fluent dark, 12 px); crops say where the window continues. Data is the ZOA scenario “S1-OAK-2/3/4 | Clean Clearances/Taxiing/VFR” (01H08FSWF5NCDXTQMQ3BWB0BND) with invented edits on each side.
