What the code does now

  • FavoriteStore.ComposeDisplay hard-codes Global, then the active airport's set, then the active scenario's set, then loaded named sets in UserPreferences.LoadedFavoriteSetIds order.
  • The only way to reorder named sets today is unload and reload: SetFavoriteSetLoaded appends to the end. Global, airport and scenario can never move.
  • LoadedFavoriteSetIds is a preference and is also saved in each layout (SavedLayout.LoadedFavoriteSetIds), so a full order needs one ordered list there that can name Global / "airport" / "scenario" slots too.
  • Sets flyout (FavoritesBarView.OnSetsClick): a MenuFlyout of named sets only, each a check-box item with StaysOpenOnClick, then "Manage sets…". No context menu, no drag. The Sets button only shows when a named set exists.
  • Editor's left list (PopulateContainers) shows every set from OrderedSets, sorted by kind then name: Global, every airport set, every scenario set, named sets with a Loaded box. It is not in bar order.
