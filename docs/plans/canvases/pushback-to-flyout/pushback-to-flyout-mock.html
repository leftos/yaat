Push back to flyout

Mock for YAAT-570 (part of YAAT-569): the designed flyout behind the Push back to strip button, in the style of the Cleared for takeoff and pattern-entry flyouts. Each row shows the target's kind, its name, the tug's path length and the command it sends. The flyout follows the target list while it is open: it starts on a placeholder or the seed targets and refills in place when the client's plan lands. Targets are illustrative, for a B738 at OAK stand 26; labels and commands are the ones the code uses today.

Settled with the owner

  1. Facings are chips on the row; each sends PUSH TE FACE N. No › second flyout (the toggle above shows the rejected layout for comparison).
  2. A click on the row sends the bare command, PUSH TE, the tug choosing the facing. A target with one facing shows "faces E" with no chip.
  3. Live fill: the seed rows show with "refining…" in the title, or "Computing targets…" with no seed; the rows are replaced in place when the plan lands, keeping the pointer's row when it survives. A click on a row that has gone does nothing.
  4. Empty: a disabled "No push targets from here" row when the plan settles empty while open; no strip button when the list is empty before the menu opens.
  5. Sections: "Behind the aircraft", then "Taxi spots", each in path-length order.
  6. Blocked targets are faded, name the blocker and send nothing on a click; a "push anyway" chip sends the forced PUSHF TF.
  7. All Commands › Push back to… uses the same designed rows: one builder for the strip flyout and the submenu.
