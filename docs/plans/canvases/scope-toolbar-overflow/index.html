YAAT-2357: the Scope toolbar on a narrow window

Four ways to handle a bar wider than its window. Each lane draws the Scope window's top edge to scale (1 CSS px = 1 DIP) at the default 1360 DIP window and at a narrow 1000 DIP one, then the open state that option depends on. The bar holds the default buttons in profile order plus YAAT-2335's TDM after MAPS, drawn as ScopeToolbar draws them: JetBrains Mono 12 px, a 28 px button in a 45 px bar, a 5 px tear-off strip left of every button but DEL TEAROFF, a separator between each two. Values are the defaults at RANGE 40 (the 120 NM band: OTHERS PARTIAL, VECTOR 1m OWN, HIST 5). The faint targets show how much of the scope the bar covers.
