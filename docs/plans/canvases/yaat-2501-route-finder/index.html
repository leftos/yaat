YAAT-2501 · Where does Find Route live in the aircraft editor?

The Scenario Editor’s Aircraft tab with SWA2190 (B737, KOAK → KLAX, parking 22) selected and its flight plan block in the 320 px detail panel. Every lane shows the same finder: the query (KOAK → KLAX, runway 30, suffix /L, airline SWA taken from the callsign), one search over csko, navdata, preferred routes and SWIM history with a badge per source and the filed count, the history source’s failure line (offline), a cruise altitude, the optional real callsign and type, and Apply. Only where it opens differs.
