# Context-layer decoder design (YAAT-343 step 3)

The design for the joint callsign and entity decoder (YAAT-1569) and the sandbox measurement it feeds (YAAT-1567). Linked from YAAT-343; delete this file once YAAT-1569 and YAAT-1567 are done (the measured result goes into the research note and `docs/speech-recognition-pipeline.md`).

Rulings in force: YAAT-343 comments 4e31176f (step 3 interview) and 95710882 (own sherpa native); YAAT-1569 comment with the three decoder rulings below. VICE is GPL-3.0: design reference only, no code.

## Rulings and decisions

Owner rulings (2026-10-30, decoder interview):

- **Airline flight number alone resolves the callsign**, at prior 0.90, and only when no other room aircraft has those digits. (7110.65 2-4-9.b.2 says not to abbreviate; controllers do, as the LiveATC set shows.)
- **GA last three characters alone resolve the callsign** ("two six foxtrot"), at prior 0.90, when unique in the room. Forms with "november" or the type name keep priority.
- **The say-again band produces SayAgain with its best guess.** The eval counts it as a rejection, not an error.

Orchestrator decisions (flagged, reversible):

- Numbers match as one digit token per digit, so grouped and digit-by-digit forms are identical ("twenty four ninety five" = "two four nine five" = `2 4 9 5`; "thirty" = `3 0`).
- Callsign score is name × code, so a strong telephony match cannot hide a wrong number.
- Acceptance thresholds test the score before the prior; the prior only ranks.
- Traffic callsigns (other room aircraft named after the addressee) resolve as Callsign entities.
- Approach rooms include the runways and approaches of every airport within 40 nm (this makes `KHWD/R28L` reachable).
- A multi-word telephony ending in `AIR`/`AIRLINES` also gets the form without that word (prior 0.95): QXE "HORIZON AIR" → "horizon".
- Distractor padding carries GA in the feed's real N-number share.
- An FBO name heard as a place ("at signature") is a landmark (`KOAK/SIGNATURE`), generated by the lexicon (YAAT-1568); spots are gold-valued `SPOT <name>`.
- The phonetic voicing fold (Z→S, V→F, D→T, B→P, G→K) is applied locally after `PhoneticFixMatcher.Phonetize`, which is unchanged.

## Token normalisation (`SpokenTokenizer.cs`)

One normaliser for transcripts and spoken forms: `SpokenTokenizer.Tokenize(string)` → `IReadOnlyList<SpokenToken>`, `SpokenToken(string Text, TokenKind Kind /* Word | Digit | Nato */, int SourceWord)`. `SourceWord` is the whitespace-word index the token came from; spans, the log-prob gate and the rewrite all use it.

- `AtcNumberParser.NormalizeDigits` (`AtcNumberParser.cs:105`) does not fit (unaligned string; it also collapses `28R`, rewrites "heading to", merges runs). The tokenizer expands numbers word by word, reading the word tables through a new `internal static bool TryGetNumberWord(string, out NumberWordKind, out int)` on `AtcNumberParser` (tables at `:36-77`):
  - digit word → 1 digit; teen → 2 digits; tens + ones → 2 digits over both source words; tens alone → `t0`;
  - "oh"/"o" between number words → `0`;
  - "hundred" → `00`, or nothing when a pair follows, or `0` when a single digit follows;
  - "thousand" → `000`, `0` before a tens word, `00` before a digit word, nothing before "X hundred".
- Lowercase, fold accents, drop apostrophes, split letter-digit boundaries (as `tools/Yaat.SpeechSandbox/WerTextNormalizer.cs:54-58`). Digit strings split to single digits; `\d{1,2}[lrc]` → digits + `left|right|center`; any other letter in a mixed token → its NATO word ("n4926f" → `november 4 9 2 6 foxtrot`).
- NATO words → `NatoPhoneticAlphabet.WordToLetter` (`NatoPhoneticAlphabet.cs:56`) → canonical `LetterToWord` word, Kind Nato. `x ray`/`x-ray` → `xray`; niner/tree/fife → digits.
- Runs of two or more single letters join (`i l s` → `ils`, as `WerTextNormalizer.cs:112`).
- Hesitation fillers `uh um ah er erm hmm` drop. The set moves to `SpokenTokenizer.HesitationFillers`; `WerTextNormalizer.Fillers` (`:39`) points at it, unchanged in content.
- "heavy"/"super" stay Words; the callsign matcher absorbs one directly after the code part. Never required.

## Spoken forms (`SpokenForms.cs`, `ContextEntityFactory`)

Forms are deduplicated after normalisation; each keeps its raw `Text` for recognizer hotwords (YAAT-1570).

- **Airline callsign:** telephony from the caller's override map (ICAO → telephony), else `AirlineTelephony.TryGetTelephony` (`AirlineTelephony.cs:29`). Forms: telephony + `FlightNumberToPairedWords` and telephony + `FlightNumberToWords` (`AtcNumberParser.cs:265`, `:242`), prior 1.0; telephony minus a trailing `AIR`/`AIRLINES` word, 0.95; flight number alone, 0.90, only when no other room aircraft has those digits. `CallsignParser.GetSpokenVariants` takes no override, so it is not used for airlines.
- **GA callsign:** `CallsignParser.GetSpokenVariants(icao, type, room)` (`CallsignParser.cs:247`: "november" + full tail, type names, unambiguous last-three with prefix, `:258-289`), plus `ShortenedNNumberSpoken` (`:206`) at 0.95, plus the last three characters alone at 0.90 when unique in the room. 7110.65 2-4-20.a.1, 2-4-9.a, 2-4-20.a.2, 2-4-14.b/c ("heavy"/"super").
- **Runway:** "runway " + `PhraseologyVerbalizer.SpellRunway` (`PhraseologyVerbalizer.cs:2001`), 1.0; bare, 0.90. Source `NavigationDatabase.GetRunways` (`NavigationDatabase.cs:1191`), both ends, keyed through `NormalizeAirport` (`:3146`).
- **Taxiway:** "taxiway " + `SpellTaxiway` (`:2186`), and bare. Names from a new `GroundLayoutSpeechNames.TaxiwayNames(layout)` in Yaat.Sim, lifting the filter at `src/Yaat.Client/ViewModels/MainViewModel.cs:2411-2421`.
- **Gate:** parking nodes → value `<name>`, forms "gate "/"parking " + `SpellDestinationName(name, noun)` (`:2214`) and bare; spot nodes → `SPOT <name>`, "spot " + the same. From `layout.Nodes` by `GroundNodeType` (`MainViewModel.cs:2342`). YAAT-1568's gate pronunciations add forms later.
- **Fix:** `GetFixPronunciations` (`NavigationDatabase.cs:857`), `GetFixDisplayName` (`:883`), `SpellFix` (`PhraseologyVerbalizer.cs:1841`), and the lowercase id. Sources: `FixesWithin(airport, radius)` (`NavigationDatabase.cs:591`) plus the aircraft's own route fixes.
- **Landmark:** from YAAT-1568's `<apt>-landmarks.json` (name + `spokenPatterns`), value `KOAK/<alias>`; passed to the builder with its airport explicitly (`CustomFixSpeechPatterns`, `:743`, is not airport-scoped). Tests build Kaiser in code until that data exists.
- **SID/STAR:** `ProcedureName(id).Tts` (`:1922`).
- **Approach:** `ApproachReadbackName.TypeAndRunway` (`src/Yaat.Sim/Pilot/ApproachReadbackName.cs:43`): "<type> runway <rwy> approach", "<type> runway <rwy>", "<type> <rwy>"; RNAV adds "r nav". Not `SpellApproach` (`PhraseologyVerbalizer.cs:2289-2325`), whose `L` branch speaks "ILS" as "india left sierra" (booked separately).
- **Airport entities:** a new `AirportContextBuilder.Build(airportId, layout, radiusNm, landmarks)` in Yaat.Sim collects runways, taxiways, gates, fixes, procedures and landmarks.

## Scoring and decoding

**Similarity** (`SpokenFormScore.cs`). `WordScore(a, b)`: 1 if equal; 0 if either is a digit, or two NATO tokens differ, or `max(|a|,|b|) < MinFuzzyChars`; else `WRaw·(1 − Lev/maxLen) + (1 − WRaw)·(1 − LevP/maxPLen)`, Lev = `PhoneticFixMatcher.Levenshtein` (`PhoneticFixMatcher.cs:149`), P = `Phonetize` (`:194`) + the voicing fold. ("kizer"/"kaiser" 0.83 with the fold; "skywest"/"southwest" 0.68.)

A span against a form splits into a name part (words) and a code part (digits, NATO): `S_name = WordScore(concat(heard name), concat(form name))` (joined without spaces, so a split word still matches); `S_code` = token-level Levenshtein alignment, Σ aligned similarities / max length (a heard Word against a form NATO token counts at WordScore ≥ `NatoCodeAccept`); `S = S_name × S_code × Prior`, a missing part counting 1. In `ExactOnly`, WordScore is 1 or 0.

**Spans.** Name part within ±1 word of the form's name length, code within ±1 token; never starting or ending inside a digit run; at most 8 tokens for callsigns, 6 for entities.

**Callsign stage.** Spans starting at offset 0-2, or ending at the last token (readbacks end with the callsign); each scored against every form of every room aircraft; best per aircraft; top K = 5.

**Entity stage**, per candidate, over the remainder (tokens outside the callsign span): the aircraft's own entities (prior 1.0), then airport entities (`AirportEntityPrior`, own wins on duplicates), then the other room callsigns' full forms (traffic). Accept on the score before the prior; choose non-overlapping spans by weighted-interval DP maximising Σ S·prior·tokens.

**Joint score.** `M` = mean of chosen spans' S·prior (1 with none). Content tokens = remainder digits, NATO words and words outside the rule literals (`NatoNearMissResolver.RuleLiterals`, `NatoNearMissResolver.cs:61`, exposed as `internal RuleLiteralWords`). Coverage `C` = explained / (explained + unexplained content). `J = S_cs × M × C^CoverageExponent`. Candidates within `CallsignJointMargin` of the best `S_cs` are eligible; highest `J` wins. State: Resolved at `S_cs ≥ CallsignAccept`, SayAgain at ≥ `CallsignSayAgainFloor` (with `BestGuess`), else NoCallsign. With no callsign, entities still resolve against airport entities at `EntityAcceptNoCallsign`.

**Log-prob gate.** Pieces group into words (a piece starting `▁` opens a word); word confidence = exp(Σ piece log-prob). If the word count differs from the hypothesis's whitespace word count, the gate is off (`ConfidenceGated = false`). A word at confidence ≥ `ConfidentWordProb` takes WordScore 0 for any non-exact match.

**Rewrite.** Accepted spans' name words and NATO near-misses are replaced by the form's words. Digits, confident words and typed input are never rewritten.

**N-best.** Decode each hypothesis; `combined_i = ln J_i + AcousticWeight·(a_i − a_0)`, or `−MissingAcousticRankPenalty·i` with no acoustic score. Only hypotheses with a Resolved callsign compete; if none resolves, hypothesis 0's result is returned.

**Typed.** The callsign resolves only on an exact ICAO token equal to a room callsign or an exact `ExactOnly` spoken match; entities by exact value suffix (`30`, `W4`, `MITOE`) or exact form; no unique-extension snap (unlike `CallsignParser.cs:527`); `RewrittenTranscript` is the input.

**Thresholds** (`DecoderSettings.cs`, one `sealed record`, every field required; `DecoderSettings.Default` holds these):

| Setting | Start | Why |
|---|---|---|
| WRaw | 0.5 | Equal weight raw and phonetic |
| MinFuzzyChars | 4 | As `NatoNearMissResolver.MinTokenLength` (`:65`) |
| NatoCodeAccept | 0.75 | Accepts whisky, gulf; rejects fox |
| CallsignAccept | 0.85 | One wrong digit in four (0.75) fails |
| CallsignSayAgainFloor | 0.60 | Below: no usable guess |
| CallsignJointMargin | 0.10 | VICE's value (design only) |
| CallsignTopK / MaxStartOffset | 5 / 2 | "correction", "and" before the callsign |
| MaxCallsignSpan / MaxEntitySpan | 8 / 6 | "november 8 2 9 8 lima heavy" |
| EntityAcceptName | 0.80 | kaiser←kizer 0.83 |
| EntityAcceptCodeOnly | 0.95 | Code-only forms effectively exact |
| EntityAcceptNoCallsign | 0.90 | Limits false insertions |
| AirportEntityPrior | 0.92 | Own entities win ties |
| Priors: bare runway / number-only / GA last-three / short GA / telephony minus AIR | 0.90 / 0.90 / 0.90 / 0.95 / 0.95 | Less evidence than the full form |
| CoverageExponent | 0.5 | Coverage counts, does not dominate |
| ConfidentWordProb | 0.97 | Sweep |
| AcousticWeight | 0.3 | Sweep 0.1 / 0.3 / 1.0 |
| MissingAcousticRankPenalty | 0.1 | Nats per n-best rank |

## Sandbox rooms and slot scoring (YAAT-1567)

- **Gold:** `slots.json` (private corpus folder), `{ "<clip id>": [ { "kind", "value", "spoken", "note"? } ] }`, read by `CorpusSlots.Read`.
- **Rooms:** `rooms.json` (private corpus folder) holds a `telephony` override map (ICAO-like prefix → telephony) and `feeds` (`airport`, `facility` gnd|twr|app, `seed`). `RoomContextBuilder`: aircraft = every distinct callsign in the feed's gold; for scored clip k, an aircraft's own entities are the non-callsign gold values of the feed's other clips (j ≠ k) naming that callsign (leave-one-out; cached per feed and k). Airport entities from `AirportContextBuilder` at 10 nm (gnd, twr) or 40 nm (app); app rooms add every airport within 40 nm's runways and approaches (`FindAirportsWithin`, `NavigationDatabase.cs:1023`).
- **Padding** to 35 aircraft: `Random(seed)`; airlines weighted by `AirportAirlines.TryGetAirlinesForAirport` arrivals (`AirportAirlines.cs:32`); numbers from `AircraftGenerator.GenerateAirlineCallsign` (`AircraftGenerator.cs:1048`), GA in the feed's real N-number share from `GenerateNNumber` (`:1064`), both made `public static`; a distractor never equals a real callsign nor shares its digits; each distractor gets 0-3 seeded airport entities as its own. Runs report padded, unpadded and oracle (the clip's own gold only).
- **Scoring** (`CorpusSlotScorer`): gold G and output O as (kind, value) multisets, O = the Resolved callsign plus entities (traffic callsigns included). Recall per kind |G∩O|/|G|; false insertions |O∖G| per kind and per 100 clips; SayAgain/NoCallsign with a gold callsign counts as a rejection, reported apart. Raw transcripts run the decoder in `ExactOnly`. A form-coverage row reports the share of gold `spoken` values equal (after tokenising) to one of the entity's generated forms. Rows per provenance and per feed; never in `ForBaseline`.
