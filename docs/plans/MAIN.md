# YAAT plans — index

Entry point for `docs/plans/`. One line per item; the detail lives in the linked subplan. Finished plans are deleted, not archived — git history is the record (a plan whose rationale or status table still has reference value is promoted into `docs/` instead). Issue-specific plans live in [`open-issues/`](./open-issues/) and are deleted once implemented.

**Order of work (steer 2026-09-07):** bug reports and feature requests — usually open GitHub issues — come first and ship in hotfix releases. The programmes below them run in the background and release with a non-hotfix. A fresh agent starts at **Bug reports and feature requests**, then the **Current programme**; **Backlog** is unscheduled findings with no report behind them. Folding the open tracker into this file is the `triage-open-issues` skill.

- [ ] **`CTO`/`CTOPP`/`GO` fire `All` and so cancel a pre-armed departure turn** (aviation review 2026-09-08, objection 3): a takeoff clearance is not a route or altitude amendment (§4-2-5, AIM 4-4-10.7), and §5-8-2.a requires the initial heading be assigned before departure — so `CTO` wiping a queued `AT 2000 TL 270` is the same defect a taxi clearance had. - [ ] **`TAXI <rwy>` silently changes the departure runway** (aviation review 2026-09-08, objection 2): `TryTaxi` writes `Phases.AssignedRunway` and `Procedure.DepartureRunway` from the taxi destination, which selects the SID runway transition; §3-7-2 NOTE 1 frames the runway in a taxi clearance as confirmation, and a real change needs an amended departure clearance (§5-8-2.b). - [ ] A chain headed by a permissive-argument special (`HO 3G; PAUSE`, `SP1 ABC; PAUSE`, `ACCEPT; PAUSE`) is never refused (finding 2026-09-08, #421 rework): `ParseTcpArg` and the scratchpad parsers accept any tail, so `CommandParser.Parse` succeeds whole and `TryParseGenuineCompound`'s NOTE-style single-parse guard returns "not a chain" — `FindNonCompoundableInChain` and `FindTakeoffPairedWithImmediateTurn` return null and the single-command router swallows the tail into the TCP/scratchpad. - [ ] `THEN`-aliased chains never reach the scoped-special splitter (csharp review 2026-09-08, #421): `CompoundPolicy.TrySplitSpecialCompound` splits the raw text on `;` while `ParseCompound` normalizes `THEN`→`;` (`CommandSchemeParser.NormalizeSeparatorAliases`), so `HO 3G THEN ACCEPT` shows one block, the unit equals the input, and the line falls to the single-command router, which swallows the tail — pre-existing; normalize before walking, but keep a `THEN` inside a free-text message intact
- [ ] The per-favorite **Width** setting is inert (finding 2026-09-08, #425): the panel fills grid cells and the inline bar never applied it, so `FavoriteCommand.ButtonWidth` and the Width spinner in the add/edit/batch flyouts only seed blank-slot widths and round-trip through export — remove the field and the spinner (a data-model change; existing favorite JSON ignores the unknown field)
