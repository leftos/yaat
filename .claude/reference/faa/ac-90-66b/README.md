## Key sections for traffic-pattern work

- **§11.3 Traffic Pattern Entry** — midfield crossing is an "alternate type of entry"; explicit guidance that aircraft should "always enter the pattern at pattern altitude, especially when flying over midfield and entering the downwind directly"
- **§11.4 Traffic Pattern Altitudes** — standard 1000 AGL; large/turbine enter at 1500 AGL or TPA+500
- **§11.5 Descent and Base Turn** — TPA maintained until abeam approach end; base turn at ~45° relative bearing from approach end
- **§9.9 Other Approaches to Land** — short, low, overhead (§9.9.3 overhead)
